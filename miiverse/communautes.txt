# Une ligne par jeu, champs séparés par « | » :
#   numéro | console (wiiu, 3ds) | auto | état | nom | Title ID | remarque | serveur annexe
#   - numéro : identifiant de la communauté, fixe pour qu'il soit le même sur tous les serveurs ;
#     jamais 100000 + 5000 × n (numéros des tournois de Mario Kart 8) ;
#   - auto : « oui » = créée à chaque démarrage si elle manque (pretendo register-games) ;
#     « non » = créée à la demande, onglet Communautés de l'interface web ;
#   - état : « validé » (essayé sur console), « non essayé », ou « serveur annexe » (la publication Miiverse
#     du jeu a besoin d'un autre serveur, indiqué dans le dernier champ, et n'a pas encore été validée avec lui) ;
#     un jeu « validé » qui a un serveur annexe a été validé avec ce serveur ;
#   - Title ID : en hexadécimal, préfixés de la région (EUR, USA, JPN, MONDE = un seul titre pour toutes) ;
#   - serveur annexe (facultatif) : serveurs dont le jeu a besoin, séparés par des espaces :
#     « nex:<ID du serveur de jeu> » (module games/), « service:<client_id>=<nom> » (service web indépendant).
#
# Sources des Title ID (relevés le 12/11/2026) : Wii U, liste « Title database » de WiiUBrew ;
# 3DS, listes de l'eShop de 3dsdb (hax0kartik/3dsdb). Chaque Title ID correspond au code produit
# de sa région dans la source (P = Europe, E = États-Unis, J = Japon, A = toutes).
