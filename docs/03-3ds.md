# 3. Connecter une 3DS

> ⚠️ **Partie non testée par l'auteur de Pretendo LAN.** Elle reprend la procédure documentée par [pretendo-docker](https://matthewl246.github.io/pretendo-docker/setup/connecting/3ds/), que Pretendo LAN conserve telle quelle. Les retours sont bienvenus (issues GitHub).

Il n'existe **pas de méthode sans modification** pour la 3DS, contrairement au SSSL de la Wii U. Il faut :

- une 3DS avec **Luma3DS** (CFW) et **GodMode9** ;
- les patchs **Nimbus** de Pretendo, installés selon le guide officiel : https://pretendo.network/docs/install/3ds ;
- une **sauvegarde NAND** faite au préalable : la procédure modifie des données de sauvegarde système.

Dans ce guide, `192.168.0.165` désigne l'IP du serveur.

## 1. Vérifier les patchs officiels

Installe Nimbus selon le guide officiel et vérifie que la console se connecte au **Pretendo officiel**.

## 2. Régler le proxy

*Paramètres de la console → Paramètres Internet → Paramètres de connexion → ta connexion → Modifier → Paramètres du proxy → Oui → Configuration détaillée* :

- serveur : `192.168.0.165` ;
- port : `8080` ;
- authentification : non.

Enregistre et retourne au menu HOME. Dans l'interface d'admin, l'onglet *Connexions* (dernières requêtes HTTP) doit montrer des requêtes de la 3DS.

Une erreur de la *Liste d'amis* indiquant que « l'accès aux services en ligne a été restreint » est **attendue** à ce stade : la console n'est pas bannie.

## 3. Envoyer les fichiers spécifiques au serveur

1. Lance **ftpd** sur la 3DS et note son IP.
2. Sur le serveur, ajoute `DS_IP=<ip de la 3DS>` dans `/opt/pretendo/.env`.
3. Lance :

   ```bash
   cd /opt/pretendo && sudo ./scripts/upload-3ds-files.sh
   ```

## 4. Créer un compte « Friends » dédié au serveur local

1. Dans **GodMode9**, lance le script *FriendsAccountSwitcher* et crée un emplacement de sauvegarde, par exemple `pretendo_official`.
2. Depuis le **Homebrew Launcher**, lance `ResetFriendsTestAccount.3dsx`. Appuie sur **A** quand une ligne blanche apparaît en haut de l'écran.
3. Ouvre la *Liste d'amis* : tu dois être en ligne avec un **nouveau code ami**. Sinon, regarde l'onglet *Connexions* et les logs de `friends`.
4. Dans GodMode9, crée un second emplacement, par exemple `local_server`.

Les emplacements sont stockés dans `SD:/gm9/out/friends_accounts/`. On bascule de l'un à l'autre avec l'option *Load a save slot* du script.

## 5. PNID

Avec l'emplacement `local_server` actif, ouvre les *Paramètres de la console* et **crée un PNID**, ou **connecte-toi avec un PNID créé sur une Wii U** de ce serveur. Le mail de confirmation arrive dans l'onglet *Mails* de l'admin, comme pour la Wii U.

## Basculer entre serveurs

| Cible | Réglage Nimbus | Certificat Juxt | Proxy | Emplacement Friends |
|---|---|---|---|---|
| **Ce serveur** | Pretendo Network | personnalisé (`upload-3ds-files.sh`) | 192.168.0.165:8080 | `local_server` |
| **Pretendo officiel** | Pretendo Network | officiel (`upload-3ds-files.sh --reset`) | aucun | `pretendo_official` |
| **Nintendo** | Nintendo Network | – | aucun | `pretendo_official` |

## Clés SpotPass 3DS (facultatif)

Elles ne servent qu'à publier du nouveau contenu SpotPass.

1. Lance le script GodMode9 de dump des clés (*DumpKeys.gm9* ou équivalent). Il écrit `SD:/gm9/aes_keys.txt`.
2. Importe ce fichier dans l'admin : onglet *Clés & certificats*, carte *SpotPass*, bouton **Importer le fichier**. En ligne de commande : `sudo pretendo boss-keys /chemin/aes_keys.txt`.
